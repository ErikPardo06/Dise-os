# Documentación para el TFG

## Título propuesto
Diseño y desarrollo de una plataforma web para la catalogación y documentación de recursos gráficos de videojuegos.

## Objetivo general
Diseñar e implementar una biblioteca web responsive que centralice la clasificación y consulta de recursos gráficos de un videojuego.

## Objetivos específicos
- Definir categorías e identificadores únicos.
- Normalizar las fichas técnicas y artísticas.
- Implementar búsqueda, filtros y vista de detalle.
- Incorporar interfaz bilingüe español/inglés.
- Publicar el resultado en GitHub.

## Tecnologías
HTML5 (estructura), CSS3 (interfaz responsive), JavaScript (lógica y renderizado), Git/GitHub (versionado) y GitHub Pages (hosting estático).

## Arquitectura
- `index.html`: estructura semántica.
- `css/styles.css`: sistema visual Studio Dark y responsive.
- `js/data.js`: catálogo de datos.
- `js/app.js`: búsqueda, filtros, idioma y fichas.

## Alcance y limitaciones
La versión actual permite consultar el catálogo, pero no editar recursos desde la web ni guardar datos de usuarios. Los cambios se realizan en el repositorio. Como trabajo futuro se propone backend, autenticación, exportación PDF/CSV y visor 3D.

## Evaluación
Documentar pruebas de búsqueda por ID/nombre/etiqueta, filtros combinados, cambio de idioma, apertura/cierre de fichas, navegación móvil y despliegue público. Incluir capturas de pantalla y recursos originales del autor en la memoria.

## Evidencias para la memoria
1. Inicio y navegación por categorías.
2. Búsqueda y filtros.
3. Ficha técnica de un recurso.
4. Vista móvil.
5. Repositorio y configuración de publicación.
6. Ejemplos de diseños originales con su proceso de producción.
