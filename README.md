## Game Design Archive
Biblioteca web Studio Dark para organizar recursos de videojuegos (materiales, edificios, vehículos, armas, personajes, entornos y objetos).

- **Aplicación:** [abrir Game Design Archive](./game-design-archive/)
- **Documentación TFG:** [docs/tfg-documentation.md](./game-design-archive/docs/tfg-documentation.md)
- **Guía de uso:** [README de la aplicación](./game-design-archive/README.md)

La aplicación está construida con HTML, CSS y JavaScript vanilla. Para publicarla, configura GitHub Pages con una fuente que sirva el contenido de `game-design-archive`, o mueve sus archivos a la raíz si deseas que sea la portada del repositorio.
